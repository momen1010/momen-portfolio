## 🎨 Design Philosophy

This portfolio is not a template. It's a **custom-designed digital identity** built around:

- **Cinematic dark aesthetic** — deep blacks, editorial typography, film grain.
- **Brutalist layout principles** — oversized type, sharp edges, no rounded fluff.
- **Street-level attitude** — UK drill, American rap, psycho-mode visual cues.
- **Production-grade code** — accessible, responsive, fast, and maintainable.

Every pixel is intentional. Every section tells part of the story.

## 📦 Getting Started

### Prerequisites
- **Node.js** ≥ 18
- **npm** ≥ 9

### Installation

```bash
# Clone the repository
git clone https://github.com/momen1010/momen-portfolio.git

# Navigate into the project
cd momen-portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
